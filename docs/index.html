ورود اطلاعات حساب

ایمیل و رمز اکانت کاتابامپت و شناسه‌ی سرورت رو وارد کن و «ذخیره در گاوصخچه» رو بزن؛ اطلاعات همین لحظه با AES-256-GCM رمز می‌شه و فقط توی مرورگر خودت قفل می‌شه — هیچ سروری در کار نیست.

همون ایمیلی که باهاش توی پنل کاتابامپ (dashboard.katabump.com) ثبت‌نام کردی.
رمز اکانت کاتابامپت؛ رمزنگاری‌شده ذخیره می‌شه و هیچ‌جا نمایش داده نمی‌شه — دکمه‌ی چشم فقط موقتاً نشونش می‌ده.
عدد آخر آدرس سرورت توی پنل، مثل /server/84521 — هر بار یکی رو وارد کن و + رو بزن. افزودن، حذف و تغییر سرورها همین‌جاست و خالی بودنش هم اشکالی نداره.

اطلاعات حساب

اینجا اطلاعات ذخیره‌شده‌ی حسابت رو می‌بینی؛ رمزت ماسک‌شده‌ست و فقط با دکمه‌ی چشم موقتاً نمایان می‌شه.

این دکمه یک index.js شخصی‌سازی‌شده می‌سازه: اطلاعات تو داخلش با AES-256-GCM قفل شده — فقط در تب Files پنل کاتابامپ آپلودش کن و Restart بزن؛ نه ترمینال، نه تایپ. این فایل مخصوص خودته، جایی نفرستش.

حذف حساب از سایت

با همین یه دکمه، همه‌ی اطلاعاتی که توی این سایت ذخیره کردی — ایمیل، رمز و شناسه‌ی سرور — همان لحظه، خودکار و بدون هیچ سؤالی برای همیشه پاک می‌شه؛ کلید رمزنگاری هم نابود می‌شه و هیچ ردی باقی نمی‌مونه.

اطلاعاتت، قفسه‌ی رمزی خودش

وقتی setup رو تمام می‌کنی، یک کلید ۲۵۶ بیتی تصادفی ساخته می‌شه و اطلاعات با AES-256-GCM رمز می‌شه. کلید به دو نیمه تقسیم و در دو جای مخفی و جدا نگه‌داری می‌شه — پس پیدا کردن یک فایل به‌تنهایی هیچی رو لو نمی‌ده.

  • هیچ متن ساده‌ای روی دیسک: نه ایمیل، نه رمز، نه شناسه
  • رمزنگاری احراز‌شده (GCM) — دستکاری فایل قابل تشخیصه
  • اطلاعات فقط به خود dashboard.katabump.com می‌ره
  • با --delete یا تایپ delete در کنسول، همه‌چیز همان لحظه و بدون رد پا پاک می‌شه

چیزهایی که بیشتر از همه پرسیده می‌شه.

شناسه‌ی سرور (Server ID) رو از کجا پیدا کنم؟
وارد پنل katabump.com شو و روی سرورت کلیک کن — توی آدرس مرورگر یه چیزی مثل dashboard.katabump.com/server/84521 می‌بینی. همون 84521 شناسه‌ی سرورته. اگه هم خالی بذاری، اسکریپت خودش دنبالش می‌گرده.
آیا رمزم امن می‌مونه؟
رمزت با AES-256-GCM رمز می‌شه و کلیدش دو تکه و در دو مسیر جدا ذخیره می‌شه؛ هیچ‌جا به‌صورت متن ساده نوشته نمی‌شه و به هیچ سروری غیر از کاتابامپ هم فرستاده نمی‌شه. فقط یادت باشه این ابزار متن‌بازه — کسی که به کل سرور (شل کامل) دسترسی داشته باشه، مثل هر ابزار خودکاری، می‌تونه از همون مسیرها استفاده کنه.
اگه کپچا بیاد چی؟
فایل index.js ساخته‌شده رو یه بار روی کامپیوتر خودت با node index.js --login اجرا کن (فقط اونجا playwright لازمه). یه مرورگر مخفی کپچای Turnstile رو خودکار حل می‌کنه و سشن ذخیره می‌شه؛ بعدش روی هاست هم از همون سشن استفاده می‌شه. بدون این هم اسکریپت هر ۱۵ دقیقه خودش دوباره تلاش می‌کنه.
روی کامپیوتر خودم هم کار می‌کنه؟
آره! از پنل حساب، index.js رو دانلود کن و روی کامپیوترت node index.js رو بزن — همون‌طور هر ۲۴ ساعت خودش تمدید می‌کنه. برای ساخت سشن کپچا هم با --login همینه.
قوانین کاتابامپ چی؟
این ابزار فقط برای سرور و اکانت خودته و رفتارش عمداً ملایمه (حداقل ۲۳ ساعت بین تمدیدهای موفق). با این حال اتوماسیون ممکنه با قوانین هر سرویسی ناسازگار باشه — مسئولیت استفاده با خودته.
چطور اطلاعات خودم رو حذف کنم؟
همه‌چیز خودکاره: ۱) توی همین سایت، کارت «حذف حساب از سایت» — دکمه‌ی «حذف اطلاعات من» رو بزن. ۲) برای اسکریپت: توی کنسولش بنویس delete یا یک‌بار node index.js --delete رو اجرا کن — فایل شخصی و سشن همان لحظه پاک می‌شن؛ اگه حذف خودکار ممکن نشد، فقط index.js رو از تب Files پنل پاک کن.
اطلاعاتی که توی سایت ذخیره می‌کنم کجا می‌ره؟
هیچ‌جا نمی‌ره! فقط داخل مرورگر خودت ذخیره می‌شه، به‌صورت AES-256-GCM رمز می‌شه و به هیچ سروری ارسال نمی‌شه. با دکمه‌ی «حذف اطلاعات من» هم داده و کلید رمزنگاری با هم برای همیشه نابود می‌شن.
اسکریپت ساخته‌شده رو چطور روی سرور بذارم؟
نه ترمینال، نه دستور: پنل کاتابامپ → تب Files → فایل index.js رو Upload کن → Restart بزن. تمام! از این به بعد هر ۲۴ ساعت خودش تمدید می‌کنه. برای تغییر اطلاعات هم همین‌جا توی سایت به‌روزرسانی کن و فایل جدید رو جایگزین قبلی کن.
